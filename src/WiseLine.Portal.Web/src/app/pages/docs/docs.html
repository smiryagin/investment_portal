Reconnect policy

Normally, sign-in is infrequent

Access tokens last 10 minutes and refresh automatically. You must sign in again after 30 days without use, at least once every 90 days, or immediately after you disconnect the client.

Final check

Ask the server what it can do

After connecting, start with a low-risk read request such as:

List my portfolios and briefly explain which investment tools are available.

The Investment MCP service provides portfolio and investment tooling. It does not place brokerage trades.
