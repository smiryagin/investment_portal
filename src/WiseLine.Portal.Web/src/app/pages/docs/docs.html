Connection guide

Connect in a few careful steps.

Create a named token in the portal, store it in an environment variable, and let your MCP client read it without placing the secret in source control.

Choose your client
Before you begin

Never paste your access token into a repository, shared message, or screenshot. The portal shows the complete token only once.

Final check

Ask the server what it can do

After connecting, start with a low-risk read request such as:

List my portfolios and briefly explain which investment tools are available.

The Investment MCP service is read-oriented for market data and portfolio analysis. It does not place brokerage trades.
